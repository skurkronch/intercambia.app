# Fotos de prueba

Una carpeta por objeto de ejemplo. Deja aquí sus fotos y córrelas así:

1. Copia las fotos a la carpeta del objeto, por ejemplo `guitarra-fender-stratocaster-demo/1.jpg`, `2.jpg`. Se ordenan por nombre y la primera es la portada. Máximo 6 por objeto.
2. Formatos: JPG, PNG, WebP o AVIF, de preferencia de menos de 1 MB y verticales (4:5).
3. Corre `npm run db:demo-photos`. Genera `supabase/demo-photos.sql`.
4. Pega ese archivo en el SQL Editor de Supabase y dale Run.

Usa fotos tuyas o con licencia libre (por ejemplo Unsplash o Pexels): estas fotos se publican con el sitio.

Antes del lanzamiento, borra los objetos de ejemplo (ver README principal) y esta carpeta.
